# 存储核心

本人托管列表包含已接管且归属于本人的云盘实例。接管实例按原 ID 更新授权，首次更新在同一事务中登记托管申请和同意回执。核验供应商身份、专用目录和凭据修订后更新容量；更新失败保留原实例、贡献和副本。

新接入和更新授权只接收账号与密码。未完成申请可由本人撤回，服务端再次核对所有者、在途操作、候选实例和远端创建意图。

## 接口与数据

模块拥有实例、准入策略、对象、副本、容量账本、任务、审计和 outbox。文件名、逻辑版本、业务访问权、贡献同意和奖励归各自模块。存储通过公开接口接收调用方授权的业务请求。

`module.json` 声明 `storage-bhpan` 为可选供应商适配。宿主注入认证、授权和驱动，通过 `Resolver` 和 `Verifier` 解析引用与核验供应商账号。未装配 BHpan 时，已装配的其他适配器照常使用。

创建、上传与下载分别检查对应动作和当前权限。HTTP 认证由宿主注入。未认证返回 401 和 `authentication_required`，认证服务不可用返回 503 和 `identity_unavailable`，重复的 `Idempotency-Key` 请求头返回 400。

HTTP 契约位于 `contracts/storage.openapi.json`，由 `make generate` 生成 Go 与 TypeScript SDK。配置缺少大小、并发、租约、校验周期或临时目录时拒绝启动。目标为三份完整副本。首次引用通常需要两个独立账号各有一份已核验副本。没有符合条件的贡献账号时，一份已核验的 COS 副本即可引用。

创建对象可提供调用身份范围内的 `client_key`，过了 24 小时请求重放窗口仍保留对象身份。相同键不能改变初始参数或复活已删除对象。受控文件公开化须保留一份同时符合新旧要求的已核验来源。提高密级后立即停止不合规交付。

放置按供应商稳定账号去重。同一贡献者的不同账号可分别计数，撤权可能同时影响多份副本。普通贡献默认只承载公开内容。

获授权管理员通过 `/api/v1/storage/contribution-admission-policy` 管理准入。限定具体实例的规则优先，其次比较贡献者规则与角色或分组规则。命中同一优先级的多条规则时，取允许级别的交集。实例本身的授权范围和期限仍须有效。

待审文件保存在获准保管该校明文的可信账号或私有 COS。受限文件从首次上传起按版本加密，只放在获准的可信账号和私有 COS。规则收窄后立即排除不合规副本，维护任务核验替代副本后清理。

写入时同时检查平台额度扣除已用与预占后的余额，以及供应商账本余量扣除预占、个人保留空间和安全余量后的余额。注册最多 100 个实例，维护每批最多 100 个对象。账号续期与凭据轮换重新验证稳定身份，旧任务不能提交新状态。

写入前持久化意图和容量预占，取得远端标识后持久化。暂存接收和远端回读流式校验 SHA-256。BHpan 达到分片条件时采用分片上传，合并前复核租约。结果未知时先核对远端，无法证明未写入时保留预占。

下载先在有界临时文件中验证完整内容，再复核当前访问权，随后从已校验暂存文件输出强 ETag 并响应 If-None-Match 与 Range 请求。损坏副本不返回部分内容或缓存命中。已发布对象可从剩余合规副本降级交付。

正常排空先验证替代副本再删除原件。清理等待运行中的写入结束，只删除隔离目录内的已知对象。BHpan 只有永久删除后按稳定 ID 确认对象不存在，才释放账本占用。

## 受限文件与密钥

Storage 为每个受限内容版本生成独立的 AES-256 数据密钥。每块明文最多 1 MiB，AES-GCM 为每块增加 16 B 认证标签。随机 8 B 前缀和 4 B 大端块号组成 nonce。认证数据绑定格式、对象 ID、分类、学校、逻辑长度、摘要、块长与块号。

带版本的主密钥封装数据密钥，封装记录与对象在同一事务保存。限定只读的供应商账号只能取得分块密文。受限内容按句柄隔离，首次受理和发布使用同一保护范围。已接收的版本不能在明文与受限之间转换。每个版本独立占用物理容量；同一版本各副本的密文相同。下载在私有暂存目录完成认证和摘要校验，复核访问权后按明文偏移处理 Range。

宿主从私有密钥文件加载活动主密钥和保留的读取密钥。新增受限写入默认关闭。恢复验收后由宿主显式开启。关闭写入时仍可使用已装载的密钥读取和修复既有副本。主密钥轮换按对象分页重新封装数据密钥，单页事务可重试。管理员核验恢复和保留期限后才能退役旧密钥。

## 数据库与运行

postgres/schema.sql 为首版迁移，由迁移身份执行。运行身份仅获 storage schema 必要表权限，audit 只追加且 audit_retention 只读。审计与 CloudEvents outbox 同事务提交；outbox 按自增序号保序并支持游标与受阻主题排除。

事件可携带 traceparent 和学校范围 schoolid，事务提交时通过 pg_notify 唤醒 relay。

服务、数据库、BHpan 连接层与托管层支持注入可选 Observer 记录脱敏操作、对象标识、错误类别与 HTTP 状态码，过滤非安全字符，严禁传入原始错误、URL 或凭据。RuntimeMetrics 只读导出本地暂存盘预算、传输并发槽占用和限速等待指标。

事件修订按对象或实例递增。任务领取与失败列表使用部分索引，升级时移除包含已完成任务的旧领取索引。

未引用上传在创建满 24 小时后进入删除。周期维护按单批上限清理到期记录。幂等响应保留 24 小时，已投递 outbox 默认保留 90 天，已完成任务默认保留 7 天，已完成托管操作默认保留 30 天。

BHpan 连接层在锁外新建或按实例账本恢复隔离目录，写入按意图前两位分片存放并兼容旧平铺文件。恢复核对稳定账号、文档库与目录名称，失败保留原会话，撤权或关闭阻止迟到生效并回收未激活引用槽位。

百个槽位按活动会话及在途接入计算。连接池另存已撤销引用的最高修订，拒绝旧修订。供应商不支持按名称定位分片时，旧大目录已有同名分片且列表无法解析，新写入兼容平铺布局。已发出写入但未取得稳定标识时，查证失败保留预占。

调用方传入授权截止时间。会话到期或撤销时关闭，后续访问返回权限拒绝。调用方取消与租约超时原样透传。可能已成功的写入先查证远端结果。

## 执行器与资源预算

executor 使用 1—16 个固定 worker 领取 PostgreSQL 任务，维护扫描按游标分批进行。空队列按配置间隔轮询，失败退避最长 30 秒；定期维护不能重置相同修订下已耗尽的重试。单对象维护失败后继续扫描其他对象，下一轮再处理失败对象。

Service 的 QuotaValidity 控制新容量样本的有效期，默认五分钟，可设为一分钟至二十四小时。注册及成功刷新均写入该期限；失败刷新不延长期限。已有样本保留已记录的截止时间，过期后停止新写入分配，直到再次获得有效样本。

BHpan 样本独立保存供应商总容量、已用和最近成功读取时间。原始剩余量取总容量减已用量，最低为零。预占、写入与释放只更新平台账本。旧记录缺少采样时间时优先刷新，原始容量待下次成功采集后补齐。

刷新失败立即标记读取失败，保留上次成功时间与原截止时间。已有放置预算沿用至原截止时间，随后停止新写入。新增申报或扩大申报条件需要当前有效的原始读数。

Executor 的 `QuotaRefreshAhead` 控制提前刷新窗口，库默认一分钟，可设为一秒至二十四小时。有效授权实例缺少采样时间、上次读取失败或样本剩余有效期进入窗口时，扫描会尝试刷新。

宿主接入有预算声明的 Service 时，刷新窗口必须短于样本有效期，且不少于维护间隔与单页超时之和。Backend 的装配默认以 12 小时为刷新目标，每 6 小时扫描，提前窗口为 6 小时 5 分钟，样本有效期为 18 小时 5 分钟。

可重试的容量读取失败按 1、2、4 分钟间隔定向补试，每轮最多三次。调用取消、权限拒绝或实例缺失时停止补试。新一轮常规维护刷新重置该实例的补试额度。

配置还要求 Lease 覆盖最大对象在配置限速下写入加回读的最短耗时。

每轮分页处理活跃对象和账号，跳过已删除墓碑，账号逐个刷新。单对象仅在需要状态更新、巡检、补副本或排空时按升序锁定必要实例。每批设置独立超时，每轮最多一千批、五分钟，超限保留游标下轮继续。

副本在核验结果达到 VerificationAge 的一半时安排巡检，超过完整有效期后不再计作健康来源。装配方分别配置维护扫描、容量采样和内容巡检周期，保持周期维护与会话复用，不把维持会话在线作为单独任务。

待执行与执行中任务默认合计最多 10000 个，可配置为 1—100000 个，所有进程通过事务协调。队列满时拒绝新增上传任务，复制只按剩余任务额度预占副本；删除和分类变更先保存停止交付状态，未入队的清理意图留在对象账本，后续维护继续入队。

单个 Service 的全局传输并发由装配方配置，单账号默认并发为 1。满载请求直接返回容量不可用，不建立无界等待队列。默认进程总传输速率为 64 MiB/s，单账号为 16 MiB/s，均可配置，允许最多 32 KiB 的单次发送突发。

带宽统计覆盖上传接收、远端读写和下载输出，同一文件的各传输阶段分别计量。带宽与账号并发的上限按 Service 实例生效，部署方须汇总各进程的资源预算。

临时磁盘默认预算为两倍最大文件大小加边界检查字节，再乘全局传输并发；可配置更低预算，但至少容纳一次传输的源文件和回读校验。创建文件前按声明大小预占，实际写入不能越界，删除成功才释放预算。

Linux 执行器在配置目录下独占 storage-staging-v1 子目录，文件权限为 0600。启动取得目录锁后只清理符合内部名称规则的普通暂存文件；符号链接、未知文件或另一个进程持锁时拒绝启动。其他系统尚无经过验证的锁实现，关闭此能力。

Executor.Stop 先停止领取，等待在途任务到指定期限，再取消超时操作。Service.Close 拒绝新操作并等待传输退出，退出前保持目录锁。任务与副本状态从数据库恢复，本地暂存内容不作为恢复来源；实例会话恢复仍由凭据装配方负责。

## 运维操作

实例命令要求 storage.operations.manage，支持暂停新写、恢复暂停、排空、撤销和调整平台额度。命令携带当前修订号与幂等键，账本、审计和事件同事务提交。命令不登录或探测供应商，不修改凭据、密级许可和授权期限。

恢复仅适用于仍在授权期限内的暂停实例；贡献者实例须具备处于活跃期内的用户贡献同意方可恢复或分配非零额度。撤销立即阻止新的供应商操作及迟到提交，重新启用须另行核验授权。排空仍等待合规替代副本。额度不能低于已用与预占之和，也不改变供应商付费额度。

失败任务重试要求 storage.operations.retry、当前对象分类授权和任务代次。仅对阻塞任务重新入队，并校验对象、实例、凭据、活跃贡献同意期限及原写入意图。撤权、到期、过时任务或队列已满时拒绝，重复请求仍校验当前权限。

重试增加任务代次并保留远端标识。结果未知的写入仍先查证远端，不能靠人工重试绕过查证或再次上传；管理员核实隔离目录未生成远端文件后，可凭修订号、幂等键和核验原因核销未知开始副本预占。

`GET /api/v1/storage/operations` 要求独立的 `storage.operations.read` 全局运维授权，在可重复读只读快照事务中批量读取实例、对象、副本与活跃任务统计，不加排他行锁、不返回凭据或摘要，也不调用供应商。对象与失败任务分别使用游标分页。

响应包含全部活动对象的状态计数，支持按异常对象、任务状态、种类和错误码筛选。

实例状态区分撤权、到期、暂停写入、容量未读取、读取失败、样本过期和容量耗尽。对象状态展示健康数、目标数与缺口。任务展示脱敏错误、尝试次数、下次执行时间及阻塞状态。实际会话与重新授权状态由托管层补充。

对象、实例或写入意图换代后，旧任务以失效原因结束，不计入待处理阻塞；当前修订下的权限拒绝和重试耗尽仍保持阻塞。历史失败次数保留在执行器观测中，不能据此判定现有副本或队列仍有故障。

## 贡献扩展接口

贡献扩展使用 `storage.contributions.read` 与 `storage.contributions.manage` 权限，按已核验的贡献者归属读取和控制实例，不获取凭据。首次绑定要求暂停、空闲且已授权的用户实例，平台实例和其他用户实例均拒绝。

首次绑定、排空后重开、提高申报额度或减少个人保留空间时，存储在实例更新事务中复核当前云盘额度。申报上限为剩余字节减个人保留和实例安全余量，最低为零。

内部 HTTP 接口在超限时返回 `storage_contribution_limit_exceeded`，读数不可用时返回 `storage_contribution_capacity_unavailable`，状态均为 409。本人贡献接口的响应以贡献契约为准。

贡献服务通过 `InspectOwnerCapacities` 批量读取当前所有者的云盘原始容量，每次最多 100 项。该 Go 接口要求可信服务身份和已核验请求人，省略不属于请求人的实例。

贡献快照返回平台占用、预占和可用容量，并附上容量读取状态和最后成功时间。时间缺失时返回 `null`。存储 HTTP 接口、审计、日志和事件均省略贡献者的云盘原始容量。

贡献控制保留单调修订与唯一贡献标识，同修订重放将截止时间统一按 UTC 比对摘要，旧 worker 不能恢复已暂停或退出的贡献。同意期限到达后，存储层独立停止新写并安排排空；后台未及时运行也不能延长用户同意。供应商授权期限不由贡献接口修改。

贡献排空结束后，存储在同一事务内核对原贡献 ID、所有者、实例修订、有效授权及新一轮同意期限。已用字节、预占字节和剩余副本均为零时，才可从 draining 切回 active。已撤销实例不能重新启用。

退出进度同时统计未删除副本、已用和预占字节。实例账本中的对象尚未清理时不能确认退出。元数据恢复保留贡献控制，普通实例更新不能移除原同意限制。

贡献候选接口在数据库查询阶段按已验证所有权、有效授权及未到期条件筛选暂停且空闲的实例，返回标识、adapter、可用量、原因、容量到期时间与授权期限。只读查询不访问供应商，也不改变实例状态；创建贡献时再次验证实际条件。

`GET /api/v1/storage/contributions/community/summary` 要求 `storage.contributions.summary`。它从贡献者实例账本汇总申报额度、有效可用容量、占用与预占及活跃数。平台自营实例和单实例标识不在该汇总中。

## 容量单位

浏览器 SDK 的 `capacity.ts` 统一提供容量显示、输入和回填。每级单位按 1024 换算。额度以整数字节传输，编辑框使用能还原原字节数的最短小数字符串。显示按当前语言舍入。

`module.json` 的 `scenario_tests` 记录各场景对应的测试文件和函数。数据库集成场景使用独立 PostgreSQL 及隔离运行身份。供应商测试使用可控驱动或协议夹具验证远端副作用。

## 在线托管接入

托管申请和凭据更新使用本人权限，管理员只能查看脱敏状态并恢复原申请。首次成功登记为暂停、零贡献额度的实例，平台只赋予配置中的公开范围；贡献额度由独立模块控制。

托管绑定在本人接口和有权管理接口返回 `account_hint`。BHpan 使用已核验绑定对应的登录名。五个字符及以上保留前两位和后两位，其余每位替换为 `*`。较短登录名只保留末位，前面至少加一个 `*`。

账号事实缺失或不可用时省略提示。服务端从现有凭据库派生标识，无需登录供应商。公开接口、审计和事件不包含该字段。

申请记录、同意版本与摘要、审计和 outbox 在同一事务提交。密码只传给私有托管端口，幂等指纹使用私钥生成。每人最多五个有效或处理中绑定，全局最多一百个有效绑定和一千条待执行或待提交结果的申请。确定性失败释放名额；恢复时在同一事务内重新占用，失败历史仍用于限流。

同账号绑定通过唯一约束排他，未注册实例的确定性失败释放账号占用。无待恢复结果、耗尽五次重试或逾期的阻塞绑定允许提交新修订恢复，最后一次执行中断后，租约到期也可提交新修订。五分钟五次登录预算使用每次执行时间，旧记录沿用最后一次时间保守计数至窗口结束。

交互验证返回专用错误码。达到限额时返回冷却秒数。本人可清理未注册且没有待恢复结果的绑定，或已撤权且无占用的绑定。

新凭据在隔离客户端验证，幂等重放先核验当前权限与缓存再决定是否访问供应商。实例更新在无预占时写回新采样容量，重授权以新核验的证据刷新容量；采样期间账本发生变化时保留更新后的账本。重授权支持跨日幂等恢复。

## 内容去重

重放保护变更仅继续原修订和原目标的迁移。已回退的请求保留其结果，后续迁移由自己的请求继续。

创建时启用 deduplicate 可获得独立逻辑引用。同一服务身份、长度、SHA-256、完整保护要求与副本策略相同的内容共用一个物理对象。每个引用保留自己的发布、修订与业务引用，物理对象继续保持三副本目标和两副本发布条件。物理对象的稳定键可用于跨幂等窗口的上传重放，仍检查当前操作权限。

摘要只用于寻找候选。没有实际上传校验或已有内容复用授权时，逻辑引用不能读取内容，也不暴露共享副本健康情况。reuse_from 要求当前 storage.objects.reuse 权限，服务端校验来源和内容标识。

保护要求不同的内容分组独立保存。保护变更按变更与指派权限复制或复用目标分组，失败可重试或传回原保护要求取消回退。变更期间暂停普通下载，具备双端审核权限时仍可审核读取原分组。

释放引用不会清除其他引用的副本。最后一个引用释放或到期后，由实际执行者身份推进物理对象清理并记录审计；仅剩已删除历史副本记录的对象直接收敛为已删除。

| STORAGE-33 | 保护、学校范围和副本策略分别隔离，目标已有内容不重复上传；重放检查当前权限，稳定键和重复迁移保留数据 |

共享引用也遵守二十四小时无业务引用到期规则，扫描限量释放过期引用。清理按上次尝试时间轮转，单组失败不会阻止对象维护。服务端拒绝绕过引用直接删除共享物理对象或修改其保护要求。

## 公开审计查询

可信 Go 调用通过 `postgres.Repository.ReadAudit` 返回 `auditquery.Batch`。backend 适配器负责认证，将当前授权与查询范围求交后传入 `Scopes`。Repository 按范围并集与全部条件过滤后分页。

时间为左闭右开区间，每次最多 101 条，按时间、模块、ID 字节序降序。Before 使用全局位置。Snapshot 固定 PostgreSQL 已提交成员，排除回填和延迟提交；删除或修改审计使旧快照失效，调用方须重新查询。

摘要只含模块、内部对象和操作者标识、时间、操作、原因、结果与范围。业务提交投影实际结果与对象所属学校范围，学校或群不明时使用 *。没有原因时为空，超出 512 字节或含控制字符的原因省略；无法证明结果时为 unknown。

已有 outbox 升级时按主题与事件修订回填序号，保留投递状态，新序号从回填范围之后分配。游标只用于单轮扫描；每轮从头读取尚未投递的事件，以覆盖上一轮后提交的事务。审计与业务同事务写入。运行身份需要读取 audit_retention，清理修订由固定 schema 的触发器更新。快照超过 256 字节或无效时明确报错。
