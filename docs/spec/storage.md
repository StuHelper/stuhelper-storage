# 存储核心

## 接口与数据

模块拥有实例、对象、副本、容量预占、任务、审计和 outbox。文件名、逻辑版本、业务访问权、贡献同意和奖励归各自模块。服务入口要求当前授权，HTTP 认证由 backend 注入，缺少身份实现时返回不可用。

OpenAPI 位于 contracts/storage.openapi.json，Go 与 TypeScript SDK 由固定版本工具生成。配置缺少大小、并发、租约、校验周期或临时目录时拒绝启动。默认三份完整副本，两份独立合规副本完成 SHA-256 校验后允许首次业务引用。

实例按供应商稳定账号去重，同一贡献者不满足不同来源约束。管理员批准具体分类、范围与期限。普通贡献仅承载公开内容，受限明文仅允许获准平台实例；加密、阅读器、直链与目录打包未实现。

容量同时受平台额度、供应商余量、个人保留空间和安全余量约束。注册最多 100 个实例，维护每批最多 100 个对象。账号续期与凭据轮换重新验证稳定身份，旧任务不能提交新状态。

写入前持久化意图与容量预占，传输前保存远端标识，完成后重读内容验证。结果未知时先核对远端；无法证明未写入时保留预占，不自动重发。后台任务使用 PostgreSQL 租约、代次及对象和凭据修订防止迟到提交。

下载先在有界临时文件中验证完整内容，再复核当前访问权。损坏副本不返回部分内容。已发布对象可从剩余合规副本降级交付；没有健康来源时停止下载和复制。

正常排空先验证替代副本再删除原件。清理等待运行中的写入结束，BHpan 移入回收站不算完成；只删除已知隔离对象，稳定 ID 查不到且明确返回不存在后才释放账本占用。

## 数据库与运行

postgres/schema.sql 为首版迁移，由迁移身份执行。运行身份仅获 storage schema 的必要表权限，audit 只追加。审计与 CloudEvents outbox 同事务提交；事件 revision 按对象或实例递增，消费者去重后重新读取当前状态。

未引用上传在创建满 24 小时后进入删除。幂等响应有效期为 24 小时。生产装配还需实现已完成事件和幂等记录清理、审计保留与备份恢复；未完成这些事项前不开放生产服务。

BHpan 连接层可以新建隔离目录，也可以按可信实例账本恢复已有目录。恢复时核对稳定账号、个人文档库、准确根标识与平台目录名称，不接受下载请求指定的个人目录。验证失败保留原会话，撤权或关闭后到达的恢复结果不能重新生效。

调用方明确传入授权截止时间，到期或撤销时关闭会话，不固定为十五分钟。该时间不代表供应商令牌寿命。会话失效与操作权限拒绝分别返回；密码保管和重新登录归装配方，连接层不自动重复可能已成功的写请求。

## 执行器与资源预算

executor 使用 1—16 个固定 worker 领取 PostgreSQL 任务，维护扫描按游标分批进行。空队列按配置间隔轮询，失败退避最长 30 秒；定期维护不能重置相同修订下已耗尽的重试。单对象维护失败后继续扫描其他对象，下一轮再处理失败对象。

待执行与执行中任务默认合计最多 10000 个，可配置为 1—100000 个，所有进程通过事务协调。队列满时拒绝新增上传任务，复制只按剩余任务额度预占副本；删除和分类变更先保存停止交付状态，未入队的清理意图留在对象账本，后续维护继续入队。

单个 Service 的全局传输并发由装配方配置，单账号默认并发为 1。满载请求直接返回容量不可用，不建立无界等待队列。默认进程总传输速率为 64 MiB/s，单账号为 16 MiB/s，均可配置，允许最多 32 KiB 的单次发送突发。

进程带宽统计覆盖上传接收、远端读写和下载输出，同一文件多个传输阶段分别计量。多个执行进程的带宽与账号并发尚无统一协调器，部署方须汇总预算，不能把单进程配置当作集群总上限。当前容量数值是配置默认值，不是压测结论。

临时磁盘默认预算为两倍最大文件大小加边界检查字节，再乘全局传输并发；可配置更低预算，但至少容纳一次传输的源文件和回读校验。创建文件前按声明大小预占，实际写入不能越界，删除成功才释放预算。

Linux 执行器在配置目录下独占 storage-staging-v1 子目录，文件权限为 0600。启动取得目录锁后只清理符合内部名称规则的普通暂存文件；符号链接、未知文件或另一个进程持锁时拒绝启动。其他系统尚无经过验证的锁实现，关闭此能力。

Executor.Stop 先停止领取，等待在途任务到指定期限，再取消超时操作。Service.Close 拒绝新操作并等待传输退出，退出前保持目录锁。任务与副本状态从数据库恢复，本地暂存内容不作为恢复来源；实例会话恢复仍由凭据装配方负责。

## 运维操作

实例命令要求 storage.operations.manage，支持暂停新写、恢复暂停、排空、撤销和调整平台额度。命令携带当前修订号与幂等键，账本、审计和事件同事务提交。命令不登录或探测供应商，不修改凭据、密级许可和授权期限。

恢复仅适用于仍在授权期限内的暂停实例。撤销立即阻止新的供应商操作及迟到提交，重新启用须另行核验授权。排空仍等待合规替代副本。额度不能低于已用与预占之和，也不改变供应商付费额度。

失败任务重试要求 storage.operations.retry、当前对象分类授权和任务代次。仅对阻塞任务重新入队，并校验对象、实例、凭据及原写入意图。撤权、到期、过时任务或队列已满时拒绝，重复请求仍校验当前权限。

重试增加任务代次并保留远端标识。结果未知的写入仍先查证远端，不能靠人工重试绕过查证或再次上传。管理端只消费脱敏状态及以上操作，不读取凭据或用户个人目录。

## 已实现验收

创建对象可提供调用身份范围内的 client_key，使对象身份不随二十四小时请求重放窗口失效。相同键不能改变初始参数或复活已删除对象。受控文件公开化须保留一份同时符合新旧要求的已核验来源；缺少时拒绝公开化。提高密级仍立即停止不合规交付。

GET /api/v1/storage/operations 要求独立的 storage.operations.read 全局运维授权。它返回最多 100 个实例、对象和失败任务分页，以及队列总数；不返回凭据引用、供应商账号、目录或内容摘要，也不调用供应商。对象与失败任务分别使用游标，不能把第一页当成全库状态。

实例状态区分撤权、到期、暂停写入、容量未知和容量耗尽。对象状态展示健康数、目标数与缺口；剩余账号或容量不足时明确报告，不能把两份说成三份。任务展示已脱敏错误、尝试次数、下一次执行时间及阻塞状态。实际会话和重新授权状态由托管层补充。

对象、实例或写入意图换代后，旧任务以失效原因结束，不计入待处理阻塞；当前修订下的权限拒绝和重试耗尽仍保持阻塞。历史失败次数保留在执行器观测中，不能据此判定现有副本或队列仍有故障。

下列核心场景使用真实 PostgreSQL 与隔离的运行数据库身份；供应商故障由可控驱动注入。连接层测试核对远端副作用，真实账号测试另外记录，不混同三账号副本演练。
